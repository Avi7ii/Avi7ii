# Compact research profile source

The main profile artwork is 840 × 256 px. The narrow version is 374 × 388 px.
All artwork uses pure SVG paths, with no scripts, `foreignObject`, network requests, raster graphics or runtime font dependency.

Regenerate with the already available Python `fontTools` package:

```sh
python3 design/build.py
```
